# 지속 지시

## 4. 모노폴리 실물 건물·권리증·카드 (2026-11-08)
사용자 지시: 주사위 두 선택판 간격은 기존의 절반. 소유 부지는 아빠/서우 색 배경으로 통일하고 그림 크기를 소유 여부로 바꾸지 않는다. 보드 안쪽 실제 건물 자리에 초록 주택 최대 4채(한 줄 최대 3개), 빨간 호텔 1개(주택 두 칸 크기)를 표시하고 독점을 알린다. 바퀴가 아래가 되게 주차 차량을 회전하고 감옥/경찰 그림은 반시계 45도 돌린다. 제공 권리증과 카드 사진에서 금액·지시를 읽어 자동 처리하고 카드 종류를 분리한다. 사진 원본은 공개하지 않는다. 대상: apps/monopoly-companion. 해제 조건: 사용자가 배치·수치를 변경할 때.

## 1. 모노폴리 도우미 화면 (2026-11-08)
사용자 말: "불필요한 작은 문장, 단어 모두 삭제. 화면을 깔끔하게 실제 필요한 내용만 유지." / "메뉴얼 다시 정리, 실제 게임판과 동일하게 모두 일치." / "게임 판 준비도 페이지를 늘리지 말고, 핵심만 간결하게, 웬만하면 한 화면에서 가이드".
대상: apps/monopoly-companion. 목적: 아빠·서우가 아이패드에서 실물 한국판을 바로 진행하도록 한다. 장식용 영어·슬로건·추천 배지·보조 카피를 넣지 않는다. 준비는 한 화면, 필수 행동과 선택은 큰 글자로 표시한다. 사용자 제공 실물 게임판·설명서 사진을 명칭과 배분의 기준으로 쓴다. 단축 규칙은 기본 규칙과 구분한다.
해제 조건: 사용자가 이 방향을 변경하거나 해제할 때.

## 3. 아이패드 가로형 모노폴리 (2026-11-08)
사용자 지시: 게임 제목과 바깥 상단 아빠·서우 막대를 삭제한다. 차례·위치는 보드 안쪽 상단에 고정한다. 일시정지·마무리·준비는 오른쪽 아래에 둔다. 주사위는 실물 두 숫자를 1~6면 터치로 선택한다. 웹 보드의 기본 색깔 띠는 없애고 소유자·건물 수를 우선 표시한다. 특수 칸 이름은 작게 표시하고 실물과 동일한 그림을 넣는다. 사용자 제공 사진 중 보드 그림 조각만 공개 자산으로 사용할 수 있고 원본 전체와 사람·배경은 공개하지 않는다. 해제 조건: 사용자가 화면 방향을 변경할 때.

## 2. 모노폴리 주사위 (2026-11-08)
사용자 선택: "실물 주사위를 굴리고 웹에 두 숫자 입력". 실제 보드와 웹 기록을 함께 유지한다. 웹 굴림 버튼은 두지 않는다. 해제 조건: 사용자가 주사위 방식을 바꿀 때.
