농장은 보상 화면이 아니라,
지뢰찾기 결과가 남는 내 세계

참고작의 ‘살아나는 월드’ 감각만 가져온다. 과일 농장의 플레이 규칙은 기존 지뢰찾기 엔진 하나이며, 농장·시설·주문은 그 승리 결과를 보여 주고 다음 판의 목표를 안내하는 메타 화면이다.

01.절대 고정: 지뢰찾기 규칙

새 퍼즐·새 수집 게임 없음. 첫 칸 안전, 숫자 단서, 연쇄 열기, 빠른 열기, 깃발(수확 표시), 마지막 칸 수동 처리, 실패 규칙은 기존 지뢰찾기 엔진을 그대로 사용한다. 농장 테마는 지뢰 아이콘만 과일·수확 표시로 바꾸며, 보드 규칙을 바꾸지 않는다.

02.참고작에서 가져올 것은 화면 언어뿐

꿈의 정원 계열

판을 이긴 뒤 숫자 보상만 띄우지 않는다. 잠긴 밭이 열리고, 낡은 상점이 고쳐지는 눈에 보이는 복구를 준다.

쿠키런 킹덤

시설을 목록 카드로 관리하지 않는다. 농장 월드에 건물이 실제로 서고, 건물을 탭하면 필요한 행동만 짧게 열린다.

타운십

수확 → 주문 → 코인 → 시설·영역 확장이라는 읽기 쉬운 성장 연결만 쓴다. 대기 타이머·작물 재배·새 퍼즐은 넣지 않는다.

03.메인 화면 = 실제 농장 맵

🏪고쳐진 상점
🌳첫 과수원
💧샘물 우물
🍯작업장
🌲잠긴 언덕 밭
과수원 플레이 →

이 화면은 배경이 아니다. 시작부터 끝까지 플레이어가 보는 실제 농장 맵이다. 오브젝트의 위치·건설 상태·잠금 상태가 저장되며, 모든 진입은 맵 위 오브젝트 탭으로만 한다. HUD는 코인·현재 목표만 남기고, 별도 홈 카드·메뉴 목록·세로 스크롤은 두지 않는다.

04.맵 오브젝트별 탭 결과

오브젝트맵에서 보이는 상태탭 결과보드 규칙 변화
활성 과수원열매가 열린 나무 · 목표 빛즉시 기존 지뢰찾기 엔진의 과일 보드로 전환없음
상점간판·손님 말풍선주문 1건 바텀시트없음
재료 시설실제 건물과 생산 아이콘생산량·다음 건설 비용만 담긴 작은 바텀시트없음
잠긴 밭안개·나무·잠금 표식코인으로 확장 확인 팝업새 과수원 외형·보상만 추가

05.넣지 않는 것

  • 매치3, 탭 수집, 별도 미니게임, 전투
  • 작물 성장 타이머, 생산 대기열, 가챠, 출석 보상
  • 웹페이지 같은 세로 스크롤 카드 목록과 긴 설명 문구
