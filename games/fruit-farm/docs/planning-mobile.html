03.전환과 메뉴 규칙

농장 → 과수원

‘첫 과수원으로 가기’ 탭은 전체 화면 전환이다. 농장 HUD는 보드 HUD로 바뀌며, 페이지 스크롤은 없다.

과수원 → 결과

패배·클리어는 보드 위 결과 오버레이로 처리한다. ‘다시 과수원’ 또는 ‘농장으로’만 제시한다.

농장 → 주문

하단 독의 주문 탭은 농장을 유지한 채 아래에서 바텀시트를 올린다. 닫으면 즉시 농장 장면으로 복귀한다.

농장 → 건설

건설도 바텀시트 하나만 열고, 다음으로 지을 수 있는 시설 1개를 우선 노출한다.
