# 15. 디오라마 미제작 도시 공용 배경

도시별 디오라마 이미지가 아직 없는 도시는 기본 우주 성운 대신 아래 5종의 공용 세로 배경을 쓴다. 도시별 완성 디오라마가 추가되면 해당 도시는 공용 배경보다 디오라마를 우선한다.

## 1. 공용 테마

| 키 | 장면 | 용도 |
|---|---|---|
| `ocean` | 바다와 섬 | 열대·해안·섬 여행지 |
| `desert` | 사막 | 건조·사막권 |
| `fields` | 들판 | 평야·초원·온대 농경권 |
| `mountain` | 산골 | 고원·산악권 |
| `winter` | 겨울 | 북방·한랭권 |

## 2. 제작·가독성 규칙

2.1. 공용 이미지는 세로 9:16의 프리렌더 2.5D 배경이며, 적·비행기·총알이 지나가는 중앙 60%를 저디테일로 비운다.
2.2. 환경 요소는 화면 가장자리·원경에 두고, 텍스트·국기·사람·탈것·UI·게임 오브젝트를 넣지 않는다.
2.3. `DIORAMA_READY`에 등록된 도시는 이 공용 테마를 쓰지 않는다. 새 도시 디오라마가 준비되면 `DIORAMA_READY`에 추가하는 것만으로 자동 우선 전환된다.

## 3. 배정 원칙

기후·지형이 비슷한 도시를 한 테마에 묶는다. 해안·도서(필리핀·동남아·파나마·파푸아뉴기니·제주)는 `ocean`, 서아시아·북아프리카·멕시코는 `desert`, 유럽 평야·아프리카 초원·남북미 평야는 `fields`, 히말라야·안데스·고원·지중해 산악권은 `mountain`, 북유럽·캐나다는 `winter`를 기본으로 한다.
