# 지뢰찾기 (Mines)

숫자를 단서로 지뢰를 피해 안전한 칸을 모두 열어내는 고전 추리 퍼즐.

## 조작

| 하려는 것 | 손가락 | 키보드 |
|---|---|---|
| 칸 열기 | 열기 모드에서 짧게 탭 | 스페이스 |
| 깃발 꽂기·빼기 | 길게 누르기, 또는 깃발 모드에서 탭 | F |
| 빠른 열기 | 열린 숫자 칸을 탭 (주변 깃발 수가 그 숫자와 같을 때) | 엔터 |
| 칸 이동 | - | 화살표 |

어느 모드에 있든 **길게 누르면 그 모드의 반대 동작**이 일어난다. 깃발 하나만 꽂을 때는 길게 누르고, 여러 개 연속으로 꽂을 때는 아래 깃발 버튼으로 모드를 바꾸는 것이 빠르다.

첫 번째로 여는 칸은 절대 지뢰가 아니다. 아무 정보 없이 첫 수에 지는 일은 없다.

## 난이도

| 이름 | 판 | 지뢰 |
|---|---|---|
| 쉬움 | 9 × 9 | 10 |
| 보통 | 12 × 12 | 25 |
| 어려움 | 14 × 18 | 55 |

## 로컬에서 실행

게임 허브 루트(`D:\claude_code\game`)에서:

```
node scripts/dev-server.mjs 8000
```

브라우저에서 `http://127.0.0.1:8000/games/mines/`.
