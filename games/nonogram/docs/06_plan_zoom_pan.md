# 06. 작업 계획 - 큰 판 확대·이동 (zoom & pan)

> 2026-08-06 착수. 아이폰 미니(폭 375)에서 10·15칸 판의 칸이 손가락보다 작아 플레이 불가한 문제의 처방.
> 확정 사항은 01_spec.md(조작) / 02_data.md(상수) / 03_architecture.md(모듈)에 반영하고, 이 문서는 그 근거와 순서를 남긴다.

## 1. 문제 (실측)

아이폰 미니 뷰포트(375×812)에서 판 크기별 셀 크기를 실측한 값.

| 판 | 세로(375×812) | 가로(812×375) |
|---|---|---|
| 5×5 | 40px | 51~68px |
| 10×10 | **20px** | 34px |
| 15×15 | **18px**(하한 걸림) | 22px |

- 애플 HIG 권장 최소 터치 타깃 44pt. 10·15칸 판은 그 절반 이하라 손가락 조작이 불가능하다.
- 원인은 **폭 병목**. 세로 공간은 절반 이상 비어 있는데(실화면 캡처 확인) 가로가 막혀 셀이 커지지 못한다.
  - 좌측 행 힌트 70.2px + 격자 정중앙 정렬용 우측 대칭 여백 70.2px = 화면 폭의 37%.
  - 대칭 여백을 걷어내도 15칸 판의 셀 상한은 (375 - 70 - 8) / 15 ≈ 20px. **한 화면에 다 넣는 한 물리적으로 불가**.
- 결론: 큰 판은 "화면에 다 넣기"를 포기하고 확대·이동을 도입한다(2026-08-06 사용자 결정).

## 2. 설계

### 2.1. 조작 규칙

- 한 손가락 = 기존 그대로 칠하기/지우기(직선 고정 드래그 유지).
- 두 손가락 벌리기/오므리기 = 확대/축소. 두 손가락 밀기 = 격자 이동.
- 확대·이동 상태의 보드 아래 빈 영역은 한 손가락 가로 이동 전용으로 쓴다. 칸 위 한 손가락은 칠하기를 유지하므로, 이 영역에서는 세로 이동·확대를 받지 않고 칠하기도 발생하지 않는다.
- 축소 하한 = 손가락으로 조작 가능한 `ZOOM.FIT_MIN_PX`. 큰 판은 전체를 작게 보기보다 이동해 본다.
- 확대 상한 = `ZOOM.MAX_PX`.
- 두 손가락이 닿는 순간, 직전에 시작한 칠하기가 아주 짧은 시간(`ZOOM.CANCEL_MS`) 안이었다면 그 묶음을 되돌린다.
  확대하려다 첫 손가락이 먼저 닿아 생기는 오조작·실수 카운트를 막는다. 이미 한참 칠하던 중이면 유지하고 드래그만 끝낸다.

### 2.2. 기본 배율 (판·화면에 따라 자동)

1. 전체가 들어가는 셀 크기(`fitCell`)를 먼저 구한다. 이때 셀이 `ZOOM.FIT_MIN_PX` 미만이면 우측 대칭 여백을 0으로 두고 다시 구한다(폭 회수).
2. `fitCell >= ZOOM.FIT_MIN_PX` → 전체가 보이고 누를 수도 있는 상태. 기존처럼 화면에 꼭 맞춘다(이동 불필요, 확대는 여전히 가능).
3. 미만이면 → 확대·이동 모드. 셀을 `ZOOM.START_PX`(손가락 기준)로 시작하고 좌상단부터 보여준다. 축소해도 `ZOOM.FIT_MIN_PX` 아래로는 내리지 않는다.

### 2.3. 힌트 고정

이동해도 행/열 숫자 힌트는 항상 보여야 푼다. 스크롤 영역 안에서 열 힌트는 위, 행 힌트는 왼쪽, 모서리는 양쪽에 고정한다(CSS `position: sticky`).
확대·이동 모드에서는 힌트의 확장 클릭 영역(`--clue-hit`)을 0으로 둔다 - 스크롤 영역 밖으로 삐져나가 잘리고, 셀이 이미 충분히 커서 필요가 없다.

### 2.4. 모듈 배치 (03_architecture.md 의존성 방향 준수)

- `src/core/zoom.js` (신규, 순수 함수 - DOM 금지): 전체 맞춤 셀 크기 계산, 확대 배율 클램프, 확대 중심 유지 스크롤 보정.
- `src/input/boardZoom.js` (신규, DOM): 두 손가락 포인터 추적 → core/zoom 계산 호출 → 셀 크기·스크롤 반영.
- `src/input/boardPanPad.js` (신규, DOM): 보드 아래 이동 영역의 한 포인터를 추적 → 가로 스크롤만 반영.
- `src/input/boardInput.js` (수정): 진행 중 드래그를 밖에서 취소하는 `cancelDrag()` 추가(경과 시간 반환).
- `src/main.js` (수정): `fitBoard`가 위 2.2 규칙으로 모드를 정하고 `boardZoom`에 한계값을 넘긴다.
- `styles/main.css` (수정): `.puzzle-wrap` 스크롤 영역화 + 힌트 sticky + 보드 아래 가로 이동 영역.
