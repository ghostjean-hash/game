# 공용 UI 부품 - 부품은 공용, 자리는 게임 (설계)

작성: 2026-09-05 / 대상 일감: T-114 / 기준 문서: 기획서 Ⅰ권 11장 · 0권 · html-game 표준 4.8 규칙 19·20

## 1. 이 설계가 푸는 문제

1.1. 기준 문서 세 층은 앞선 커밋(`0b41941`)에서 같은 세대로 맞췄다. 이 설계는 그 규격을 코드에 옮기는 부분만 다룬다.

1.2. 실측으로 드러난 것은 정리 대상이 아니라 **이미 나 있는 결함**이다. 공용 상단 띠가 폐기되면서, 그 띠에 기능을 위임했던 게임 둘이 기능을 통째로 잃었다.

| 게임 | 소리 끄기 | 환경설정 | 잠깐 멈춤 | 되돌아가기 |
|---|---|---|---|---|
| 테트리스 | 있음 | 없음 | 있음 | 있음 |
| 스도쿠 | **없어짐** | 없음 | 있음 | **없어짐** |
| 러시아워 | **없어짐** | 시작 화면에만 | 없음 | **없어짐** |
| 노노그램 | 있음 | 없음 | 없음 | 있음 |
| 비행 슈팅 | 있음 | 시작 화면에만 | 있음 | 있음 |
| 지뢰찾기 | 있음 | 없음 | 있음 | 있음 |

1.3. 러시아워는 지금 **어느 화면에서도 소리를 끌 수 없다**(`src/` 전체에 음소거 호출 0건). 스도쿠도 같다. 두 게임은 자기 마크업으로 버튼을 만들지 않고 "공용 띠가 갖는다"는 주석과 함께 위임했는데, 그 띠가 화면에 없는 정도가 아니라 **아예 만들어지지 않는다**(`mountTopbar` 호출처 0건 + `frame.css:107`의 전역 감춤).

1.4. 환경설정은 여섯 게임 모두 플레이 중에 닿을 수 없다. 넷은 기능 자체가 없고, 둘은 시작 화면에서만 열린다.

## 2. 순서를 바꾼다 (기획서 9.1 정정 제안)

2.1. 기획서 9.1은 "문서 정렬 → 잔재 제거 → 부품 신설 → 게임 적용" 순서로 적었다. 실측 결과 이 순서는 위험하다 - 잔재(공용 띠 부품과 게임들의 위임 주석)를 먼저 걷으면, 스도쿠·러시아워가 기능 없는 상태로 남는 구간이 생긴다.

2.2. 아래 순서로 바꾼다. 잔재는 대체물이 실제로 선 뒤에 걷는다.

```
걸음 1  공용 부품 신설          게임 미변경. 확인용 화면으로만 검증
걸음 2  게임에 붙이기 + 기능 복구  스도쿠·러시아워 먼저, 나머지 넷은 갈아끼움
걸음 3  폐기 잔재 제거           대체물이 선 뒤에만
```

2.3. 이 정정은 기획서 9.1 본문에도 반영한다(문서와 코드가 어긋난 채 두지 않는다).

## 3. 걸음 1 - 공용 부품 신설

### 3.1. 새로 만드는 파일 둘

**`shared/frame/settings.js`** - 환경설정 그릇

- `createSettings({ audio, save, mountTo })` 하나를 내보낸다. 반환은 `{ open(), close(), addItem(item), el }`.
- 열리는 모양은 덮는 카드다. 잠깐 멈춤·결과와 같은 층(`.gg-layer`)을 쓰고 전용 화면을 새로 만들지 않는다.
- **소리 항목을 공용이 기본으로 넣는다.** 게임이 아무것도 하지 않아도 환경설정을 열면 소리 켜고 끄기가 맨 위에 있다. 상태는 `audio.isMuted()`에서 읽고 바뀌면 `audio.setMuted()` + `save.writeMuted()`를 거친다(localStorage 직접 접근 금지 - 클라우드 동기화 신호가 끊긴다).
- 게임이 `addItem`으로 항목을 뒤에 붙인다. 항목 종류는 둘 - 켜고 끄는 것(`toggle`)과 하나 고르는 것(`select`).
- 되돌아가기 한 번에 닫히고 계단을 깊게 하지 않는다(`stack.js`를 건드리지 않고 덮는 층으로만 처리).

**`shared/frame/overlay.js`** - 덮는 카드와 알림 쪽지

- `openCard({ title, bodyEl, actions })` - 화면을 덮는 층 위에 카드 하나를 띄운다. 바깥을 눌러 닫기, 되돌아가기로 닫기를 공용이 처리한다.
- `showToast(text, ms)` - 잠깐 떴다 사라지는 쪽지. 지금 `shared/ui.js:72`에 있는 것을 프레임 부품으로 옮기고, 자리·머무는 시간·사라지는 방식을 공용이 정한다.
- `cards.js`(잠깐 멈춤·결과)는 이 부품 위에 얹는 것이 아니라 그대로 둔다. 이미 잘 도는 것을 건드리지 않는다.

### 3.2. 손보는 파일

**`shared/frame/frame.css`**

- `.gg-ic`(아이콘 버튼)를 실제로 쓸 수 있게 정비한다. 지금 정의는 있으나 아무도 쓰지 않아 크기·눌린 상태·켜진 상태 표시가 검증된 적이 없다. 게임 여섯이 각자 만든 `.icon-btn` 여섯 벌이 실제로 쓰는 크기(28~34px)를 조사해 그 범위로 맞춘다.
- 환경설정 카드와 알림 쪽지 스타일을 더한다.
- **간격·글자 크기를 리터럴로 새로 적지 않는다.** 지금 `frame.css`는 `--sp-*`·`--r-*` 토큰을 한 번도 쓰지 않고 `11px 12px`·`13px` 같은 값을 직접 적고 있다. 새로 더하는 규칙은 토큰을 쓰고, **기존 리터럴은 이 판에서 건드리지 않는다**(범위 밖).

**`shared/tokens.css`**

- `--accent-fg` 하나만 더한다. 프레임이 요구하는데 공용 토큰에 없어 게임 셋이 각자 선언하고 있다.
- 그 밖의 토큰 정비(글자 크기 체계 신설 등)는 이 판의 범위가 아니다.

**`shared/frame/index.js`**

- `createSettings`·`overlay`를 조립에 넣고 반환 객체에 `settings`·`overlay`를 더한다.
- **시작 화면 추가 항목 줄에 환경설정을 공용이 자동으로 넣는다.** 지금은 게임이 `extras`에 손으로 적어야 하고 그래서 둘만 갖고 있다. 규칙 20이 "모든 게임이 갖는다"이므로 공용이 넣는 것이 맞다. 게임이 `extras`에 이미 환경설정을 적어 두었으면 중복해 넣지 않는다.
- 반환 객체의 미사용 API(`start`·`toTitle`·`finish`·`destroy`)는 이 판에서 건드리지 않는다(범위 밖).

### 3.3. 확인 경로

`shared/frame/demo.html`에 환경설정 카드·아이콘 버튼·덮는 카드·알림 쪽지 넷을 세운다. 이 화면을 실브라우저로 열어 눈으로 본다. 확인용 화면이 없으면 걸음 1이 끝났는지 볼 방법이 없다.

## 4. 걸음 2 - 게임에 붙이기

### 4.1. 잃어버린 기능부터 되돌린다

**스도쿠** - 플레이 화면에 소리 버튼과 되돌아가기를 되돌린다. 공용 `.gg-ic`를 쓰고 자리는 게임이 정한다(지금 `.topbar` 자리). `index.html:24-25`의 위임 주석을 지운다.

**러시아워** - 소리·되돌아가기를 되돌리고 환경설정을 플레이 중에도 열 수 있게 한다. `index.html:25-26`과 `src/main.js:416-417`의 위임 주석을 지운다. `style.css:120-137`의 띠 주석도 사실과 어긋나므로 함께 정리한다.

### 4.2. 나머지 넷은 갈아끼운다

테트리스·노노그램·비행 슈팅·지뢰찾기는 자기 버튼이 이미 살아 있다. **동작은 그대로 두고 껍데기만 공용 부품으로 바꾼다.** 각 게임의 `.icon-btn` 정의를 지우고 `.gg-ic`를 쓴다. 자리를 잡는 규칙(`.pc-tl`·`.topbar` 등)은 게임이 계속 갖는다 - 자리는 게임 몫이다.

### 4.3. 환경설정 항목

여섯 게임 모두 시작 화면에서 환경설정이 열린다(걸음 1에서 공용이 넣는다). 게임이 더할 항목은 지금 있는 것만 옮긴다 - 러시아워와 비행 슈팅의 기존 설정 모달 내용. 새 설정 항목을 이 판에서 만들지 않는다.

### 4.4. 검증 순서

게임 하나(러시아워 - 피해가 가장 크고 설정 모달이 이미 있어 옮길 것이 분명하다)를 먼저 끝내고 규격의 빈틈을 찾은 뒤 나머지 다섯에 간다.

## 5. 걸음 3 - 폐기 잔재 제거

대체물이 선 뒤에만 한다.

5.1. `shared/frame/topbar.js` 삭제(109줄).

5.2. `shared/frame/frame.css`의 띠 스타일 삭제(38~107행 구간). 같은 구간의 죽은 규칙 하나(`.gg-title-hero`의 `top`이 108행과 147행에 두 번 선언되어 앞엣것이 죽어 있다)도 함께 지운다.

5.3. 게임 여섯의 "상단 띠 감추기" 규칙 삭제 - `tetris/style.css:29-31`, `sudoku/style.css:45-47`, `mines/styles/main.css:12-14`, `nonogram/styles/main.css:47-49`, `flightshooting/styles/main.css:161-163`, `rushhour/style.css:120-137`.

5.4. `service-worker.js:199`의 PRECACHE에서 `topbar.js`를 빼고 새 파일 둘을 넣는다. 캐시 번호를 올린다.

5.5. `tests/frame.test.mjs` 세 항목 정리 - 파일 존재 강제(191행 목록에서 제거), 조립에서 부르면 실패(210행 - 파일이 없어지므로 삭제), PRECACHE 등재 강제(225행 목록에서 제거). **대신 "게임이 아이콘 버튼·덮는 카드·알림 쪽지·환경설정을 자기 폴더에서 새로 정의하지 않는다"는 검사를 새로 넣는다**(규칙 19를 기계가 지키게 한다).

5.6. `shared/fullscreen.js`(434줄)와 `tests/fullscreen.test.mjs`(418줄) 삭제. 부르는 곳이 0건이고 기획서 0권 4.2가 폐기를 확정했다. `.claude/deploy.json`의 검사 실행 목록에서도 뺀다.

## 6. 무엇으로 확인하는가

6.1. **기계 검사** - `node tests/frame.test.mjs` 외 루트 검사 전량. 규칙 19를 지키는 새 검사 항목이 실제로 위반을 잡는지 일부러 어겨 확인한다.

6.2. **확인용 화면** - `shared/frame/demo.html`에서 부품 넷.

6.3. **실화면 전수** - 게임 여섯을 실브라우저로 열어 아래를 밟는다. 이것이 이 판의 진짜 합격 조건이다.
- 시작 화면에서 환경설정이 열리는가(여섯 전부)
- 환경설정에서 소리를 끄면 실제로 소리가 꺼지고, 나갔다 들어와도 꺼진 상태인가
- 플레이 중에 소리·되돌아가기에 닿는가(스도쿠·러시아워가 되돌아왔는가)
- 되돌아가기 한 번에 환경설정만 닫히고 화면이 뒤로 밀리지 않는가
- 갈아끼운 넷의 버튼 모양·크기가 전과 달라져 화면이 깨지지 않았는가

6.4. 배포본을 다시 굽는 절차는 이 폴더에 없다(정적 웹). 캐시 번호만 올린다.

## 7. 하지 말 것

7.1. `shared/base.css`의 `.btn`·`.modal`·`shared/ui.js`의 `showModal`·`showToast`를 **지우지 않는다.** 앱 셋(영어 독해·영어 단어장·lotto)이 쓰고 있고, 앱은 이 판의 범위가 아니다(기획서 0권 3.3).

7.2. 게임 고유 조작 부품을 건드리지 않는다 - 숫자 입력판, 색 고르는 줄, 모드 전환.

7.3. `cards.js`(잠깐 멈춤·결과)의 동작을 바꾸지 않는다.

7.4. `frame.css`의 기존 리터럴 값, 토큰 체계 신설, 미사용 API 제거는 범위 밖이다.

7.5. 게임의 자리 잡는 규칙(어디에 놓는가)을 공용으로 끌어올리지 않는다. 자리는 게임 몫이다.

7.6. 새 설정 항목·새 기능을 만들지 않는다. 있는 것을 옮기고 잃은 것을 되돌리는 판이다.

## 8. 모델 배정

공용 인터페이스 변경 + 영속 데이터(설정 저장) 관련이라 **구현도 오퍼스**다. 소넷으로 내리지 않는다.
