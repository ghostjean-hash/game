0.게임 플랫폼 이동 구조

게임 허브라는 하나의 웹 주소 안에 게임과 앱이 여러 개 들어 있음. 이 문서는 그것들 사이를 오가는 규칙을 정함. 게임 하나를 열고 난 뒤의 화면 흐름은 Ⅰ. 게임 시작 흐름 공용 프레임이 맡으며, 이 문서가 그 상위임.

1.

세 층

NAV-LAYER

플랫폼은 세 층으로 되어 있음. 층이 다르면 이동 방식도 다름.

FIG NAV-01허브가 뿌리이고 게임·앱이 그 아래 나란히 있음. 게임끼리, 앱끼리 직접 오가지 않음.
허브 첫 화면 - 뿌리
  • 게임 목록, 앱 목록, 정보 세 칸으로 나뉨. 어느 칸을 보고 있는지는 아래쪽 도크가 정함(2장)
  • 등록부 파일 두 개(games/_registry.json, apps/_registry.json)가 목록의 유일한 출처임. 카드를 손으로 적지 않음
게임 - 공용 프레임을 쓰는 것
  • 연 뒤의 화면 흐름은 Ⅰ권 규격을 따름. 허브로 나오는 문은 게임 홈 화면의 <- 하나뿐임(3.1)
앱 - 게임이 아닌 것
  • 영어 독해·영어 단어장·lotto 셋. 한 판이 있는 놀이가 아니라 계속 쓰는 도구라 시작 화면·결과 카드가 뜻을 갖지 않음
  • 지금은 공용 프레임 밖에 있음. 어디까지 함께 쓸지는 3.3에 적음
2.

허브 안에서의 이동

NAV-HUB

2.1.하단 도크가 주 이동 확정 2026-08-24

허브 첫 화면의 칸 이동은 화면 아래에 붙은 도크가 맡음. 위쪽 띠나 좌우 넘김을 쓰지 않음.

칸은 셋 고정 - 게임 · 앱 · 정보
  • 칸이 늘어나도 도크 줄을 새로 만들지 않고 기존 칸 안에서 나눔
지금 보고 있는 칸을 눈에 띄게 표시함. 어느 칸에 있는지 모르는 상태를 만들지 않음
도크는 손이 닿는 아래쪽에 둠
  • 한 손으로 드는 기기에서 위쪽 띠는 엄지가 닿지 않음. 홈 표시 막대와 겹치지 않게 여백을 둠

2.2.카드를 눌러 들어감

게임·앱으로 들어가는 것은 목록의 카드를 누르는 것 하나임. 카드에는 이름, 한 줄 설명, 상태(놀 수 있음·만드는 중)가 보임. 만드는 중인 것도 목록에 두되 그 사실을 카드에 적어, 들어갔다가 빈 화면을 만나는 일을 막음.

3.

안에서 밖으로 나오는 길

NAV-EXIT

3.1.게임에서 나오는 문은 하나 확정 2026-08-24

게임에서 허브로 나오는 길은 게임 홈 화면의 <- 하나뿐임. 화면 위에 떠 있는 별도의 허브 버튼을 두지 않음.

이 버튼은 공용 프레임이 붙임. 게임이 자기 손으로 만들지 않음
플레이·잠깐 멈춤·결과 화면에는 이 문이 없음
  • 거기서는 되돌아가기가 한 칸씩 올라가고, 홈 화면에 닿았을 때 비로소 나갈 수 있음(Ⅰ권 4.2)
  • 판이 진행 중인데 한 번에 게임 밖으로 나가면 진행이 사라지는 사고가 나기 때문임
게임은 주소를 스스로 바꾸지 않음
  • 이동은 공용 프레임을 거침. 게임이 직접 허브 주소로 튀는 길을 만들면 되돌아가기 계단이 어긋남

3.2.기기 되돌아가기와 같은 결과

화면 안의 <-와 기기 자체의 되돌아가기 동작은 항상 같은 곳으로 감. 둘이 다르게 동작하면 어느 쪽을 눌러야 할지 사용자가 매번 시험해야 함.

3.3.앱은 아직 이 규칙 밖 미적용

앱 셋(영어 독해·영어 단어장·lotto)은 공용 프레임을 쓰지 않고 각자 자기 방식으로 허브에 돌아옴. 한 판이 있는 놀이가 아니라 시작 화면·결과 카드가 뜻을 갖지 않기 때문임.

다만 허브로 돌아오는 문의 모양과 자리, 그리고 기본 부품은 게임과 같아야 함. 앱만 다르게 생긴 버튼과 다르게 열리는 덮는 카드를 쓰면 같은 허브 안에서 조작감이 갈림. 어디까지 함께 쓸지는 게임 쪽 부품 공용화(Ⅰ권 11장)가 선 뒤에 정함.

4.

설치해서 여는 경우

NAV-APP

허브는 웹 주소로도 열리고, 홈 화면에 추가해 독립 창으로도 열림. 둘 다에서 같은 흐름이 성립해야 함.

4.1.독립 창으로 열리게 함 확정 2026-08-24

게임·앱마다 자기 설치 정보를 가짐
  • 독립 창으로 열리도록 지정하고, 시작 주소는 자기 폴더, 적용 범위는 허브 뿌리로 둠. 그래야 설치한 뒤에도 허브로 돌아올 수 있음
운영체제가 쓰는 영역은 침범하지 않음
  • 노치·홈 표시 막대 안쪽 안전 영역에만 화면을 그림

4.2.전체화면 버튼은 두지 않음 확정 2026-08-24

브라우저 전체화면을 켜고 끄는 버튼과 아이폰용 홈 화면 추가 안내를 폐기함. 아이폰이 동영상 외 전체화면을 열어주지 않아 기기마다 결과가 갈렸고, 안내를 아무리 잘 그려도 사용자가 따라 해야 얻어지는 것이었음. 설치해서 독립 창으로 여는 길 하나로 통일함.

폐기 결정 이전에 만든 전체화면 처리 코드가 아직 저장소에 남아 있으나 부르는 곳이 없음. 정리 대상임.
