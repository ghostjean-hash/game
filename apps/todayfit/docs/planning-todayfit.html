4.1 오늘 S-01

오늘 화면은 다섯 상태 가운데 하나를 표시한다. 진행 중 세션이 있으면 나머지 네 상태보다 이어하기 안내를 앞에 둔다.

상태조건표시 항목
이어하기진행 중 세션 존재중단 지점의 운동명과 세트 번호, 이어하기 안내
시작 대기오늘 계획 존재, 수행 기록 없음오늘 날짜와 요일, 예정 시간, 루틴 이름, 운동 목록(순서 · 운동명 · 세트 수 × 반복 횟수), 예상 총 운동시간, 다음 예정 운동 날짜와 시간
남은 운동 계속오늘 수행 기록의 전체 상태가 부분 완료, 재개 대상 세트 잔여지금까지의 결과(완료 운동 수 / 전체 운동 수, 누적 운동시간), 남은 운동 목록(운동명 · 남은 세트 수), 남은 예상 운동시간, 다음 예정 운동 날짜와 시간
완료오늘 수행 기록의 전체 상태가 완료당일 결과 요약(완료 운동 수 / 전체 운동 수, 총 운동시간), 다음 예정 운동 날짜와 시간
계획 없음오늘 날짜별 계획 없음오늘 예정된 운동 없음 표기, 다음 예정 운동 날짜와 시간
재개 대상 세트 - 건너뛰지 않은 운동의 미완료 세트. 상세는 7.6 같은 날 재개 참조
건너뛴 운동만 남은 부분 완료 - 재개 대상이 0개이므로 완료 상태와 같은 결과 요약만 표시

운동 실행 상태 전환 규칙

TF-7

운동 실행은 구간 넷을 오간다. 준비 구간은 세션마다 한 번, 운동과 휴식은 세트 수만큼, 전환은 운동과 운동 사이에서 돈다. 마지막 운동 뒤에는 전환 구간을 두지 않는다. 네 구간 가운데 운동 구간만 시간으로 끝나지 않고 사용자의 다음 버튼으로 끝난다 - 횟수 기준 운동에서는 실제 반복 완료가 경과 시간보다 우선하기 때문이다.
