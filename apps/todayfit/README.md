# 오늘운동 (TodayFit)

월 단위로 짜 둔 운동 계획을 그날 실행하고, 계획 대비 실제 수행 결과를 남기는 개인 전용 웹앱.

## 쓰는 법

1. 설정에서 운동 종목을 등록한다.
2. 그 종목을 묶어 루틴을 만든다.
3. 요일 규칙에 요일별 시간과 루틴을 연결한다.
4. 달력에서 그달 계획을 생성한다.
5. 계획일에 오늘 화면에서 운동을 시작한다.

## 운동 중 조작

폰을 화면 켠 채로 거치하고 소리로 진행을 듣는다. 버튼은 셋이다.

- **다음** - 세트를 마쳤을 때 누른다. 이 버튼을 눌러야 세트가 완료로 기록된다.
- **다음 길게** - 지금 운동 전체를 건너뛴다. 3초 안에 되돌릴 수 있다.
- **일시정지 / 운동 종료** - 필요할 때만.

휴식과 운동 사이 이동은 시간이 알아서 넘긴다. 세트만 손으로 끝낸다.

## 로컬 실행

저장소 루트에서 정적 서버를 띄운다.

```
node scripts/dev-server.mjs 8000
```

브라우저에서 `http://127.0.0.1:8000/apps/todayfit/`.

## 테스트

```
cd apps/todayfit
node tests/run-node.js
```
