# 모노폴리 클래식 동행

## 1. 목적
실물 클래식 보드를 사용하는 부모와 초등학생 2인용 진행 도우미. 게임 복제나 디지털 은행이 아니다.

## 2. 기준
기획·규칙·작업 계획은 `docs/planning.html`이 원본이다. 수정 순서는 문서 → 코드 → 검증.
공식 기본 규칙과 제안한 우리 집 규칙을 명확히 구분한다. 판별 도시명·금액은 실물 카드 우선.

## 3. 구현
빌드·외부 패키지 없이 HTML/CSS/일반 JS. index.html 직접 열기와 정적 서버 모두 지원한다.
data.js는 한국판 40칸/지폐/아빠·서우 기본 이름, core.js는 시간·차례·결산, board.js는 말·현금·권리증·건물·저당의 순수 기록 함수, manager.js는 간단 규칙, app.js는 한 화면 준비·보드 진행·저장을 담당한다.
실물 주사위 두 면을 각각 1~6의 점 모양 버튼에서 선택한다. 웹 굴림 버튼은 넣지 않는다. 사용자 추가 사진의 도시 권리증 22장과 카드 28장(사회사업기금13/찬스15)을 data.js에 등록했다. 일반 임대료·독점·건축비는 자동 계산하며 카드 제목을 고르면 지시를 처리한다. 사진에 없는 카드는 직접 입력한다. 기존 판은 hydrate로 수치를 보완하되 현금·소유·건물·차례를 보존한다. 원본 사진 전체·사람·배경은 공개하지 않는다. 사용자 요청으로 추출한 특수 칸 그림만 assets/board에 둔다.
아이패드 가로형에서 차례·위치·잔액은 보드 안쪽 상단 고정, 일시정지·마무리·준비는 오른쪽 아래다. 도시 기본 색 띠 대신 안쪽 중립 건물 자리에 초록 주택 3+1/빨강 호텔 두 칸을 그린다. 소유자는 부지 전체 배경과 이름으로 통일하고 독점을 표시한다. 특수 칸 그림 크기는 소유 여부와 무관하다. 화폐 M은 가는 세리프 기호로 숫자와 구분한다.
한 판은 한 기기의 로컬 저장만 사용한다. 다른 게임·공용 코드·클라우드 설정은 변경하지 않는다.
준비는 기본/30분/60분 하나로 선택한다. 기본은 minutes:null, 부지 없이 M1500, 경과 시간 표시이며 자동 종료하지 않는다. 30/60분은 기존 사전 세트 구입과 준비·결산 10분 예약이다. 과거 45분 판도 그대로 이어간다. playerColors는 두 팔레트 ID를 저장하며 색이 없는 기존 판은 파랑/분홍이다. 상대 색을 고르면 교환한다. 말·소유 배경·차례·현재 위치 글로우에 같은 색을 쓴다. UI 아이콘과 M 중간 두 줄은 SVG로 그린다. 사용자 답변과 최신 구현 이력은 NEXT-SESSION.md/PROGRESS.md를 참조한다.

## 4. 확인
`node --test apps/monopoly-companion/tests/*.test.mjs`.
브라우저에서 준비 → 진행 → 규칙 → 결산, 새로고침 복원과 좁은 화면을 확인한다.
