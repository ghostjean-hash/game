# 모노폴리 클래식 동행

## 1. 목적
실물 클래식 보드를 사용하는 부모와 초등학생 2인용 진행 도우미. 게임 복제나 디지털 은행이 아니다.

## 2. 기준
기획·규칙·작업 계획은 `docs/planning.html`이 원본이다. 수정 순서는 문서 → 코드 → 검증.
공식 기본 규칙과 제안한 우리 집 규칙을 명확히 구분한다. 판별 도시명·금액은 실물 카드 우선.

## 3. 구현
빌드·외부 패키지 없이 HTML/CSS/일반 JS. index.html 직접 열기와 정적 서버 모두 지원한다.
data.js는 한국판 40칸/지폐/아빠·서우 기본 이름, core.js는 시간·차례·결산, board.js는 말·현금·권리증·건물·저당의 순수 기록 함수, manager.js는 간단 규칙, app.js는 한 화면 준비·보드 진행·저장을 담당한다.
실물 주사위 두 숫자를 입력한다. 웹 주사위 버튼은 넣지 않는다. 사진 없는 도시 임대료·건축비는 처음 필요할 때 권리증을 확인받아 기억한다. 사진을 공개 저장소나 웹에 올리지 않는다.
한 판은 한 기기의 로컬 저장만 사용한다. 다른 게임·공용 코드·클라우드 설정은 변경하지 않는다.

## 4. 확인
`node --test apps/monopoly-companion/tests/*.test.mjs`.
브라우저에서 준비 → 진행 → 규칙 → 결산, 새로고침 복원과 좁은 화면을 확인한다.
