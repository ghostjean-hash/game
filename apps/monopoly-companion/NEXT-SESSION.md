# 모노폴리 다음 세션

## 1. 현재 상태 (2026-11-08)
토큰 부족으로 기록했던 여덟 수정은 사용자 재개 지시와 두 질문의 답변을 받아 구현했다. 이전의 기록만 제한과 답변 대기는 해제됐다. 같은 질문을 다시 하지 않는다. 배포 성공 여부는 실제 Pages 상태와 외부 화면 확인 후 채팅으로 보고한다.

## 2. 확정한 동작
1. 준비는 기본 / 30분 / 60분 한 선택이다. 기본은 부지 없이 각자 M1500, 시간 제한 없음이다. 경과 시간을 표시하고 마무리·파산 종료를 지원한다. 30/60분은 사전 부지 세트를 구입하고 준비·결산 10분을 제외한 20/50분을 플레이한다.
2. 아빠·서우 카드에서 고르는 색은 말·소유 배경의 플레이어 색이다. 부지 세트 색이 아니다. 여섯 팔레트 중 고르며 상대 색 선택 시 서로 바뀐다. 말·소유 배경·차례 아바타·현재 위치 강조에 반영된다. 새 판에 저장하고 새로고침·이어하기로 유지한다. 기존 색 정보 없는 판은 기존 파랑/분홍으로 표시한다.
3. 기본 준비의 권리증 문구는 도시·역·공공 기관의 권리증 전부가 은행 소유라는 뜻으로 명확하게 수정했다.
4. 말·카드·은행은 하나의 회색 배경 그룹이다.
5. 시작 버튼의 글자와 SVG 화살표는 세로 중앙에 정렬된다.
6. UI 아이콘은 SVG이며 앞서 요청한 실물 보드 그림은 유지했다.
7. M 중간 두 줄은 SVG로 그려 기존 글꼴과 CSS 획의 겹침을 제거했다.
8. 현재 차례 말의 칸에는 해당 플레이어 색의 은은하고 정적인 글로우가 적용된다.

## 3. 검증과 보존 범위
자동 검사 47건 통과. 기본 무제한의 장시간 미종료·수동 같은 차례 종료, 30/60분 생성, 색 교환/저장 유효성, 색 정보 없는 기존 45분 판을 검사했다. 8001의 분리된 검수 판에서 기존 45분 판 현금·말 위치·일시정지 시계 보존, 색 교환, 기본 부지0/M1500 시작, 두 사람이 구입한 부지의 선택 색 반영, 새로고침 후 위치·잔액·색·경과 시간 복원, 수동 마무리와 M1500/M1500 결산, 30/60분의 부지6개 및 20:00/50:00 시작을 확인했다.
가로 1366×1024/1194×834/1024×768에서 세 모드가 한 화면에 들어가고 색 선택이 넘치지 않는다. 기본 시작 버튼 하단은 833.421875/806.671875/741.0625px다. 버튼 글자와 화살표의 세로 중심 차이는0px다. 브라우저 오류 없음. 실제 아이패드 Safari 실기기는 미확인이다.

## 4. 작업 파일과 주의
기획은 docs/planning.html 0.4~0.5, 데이터는 data.js, 세션/색 선택은 core.js, 준비/게임 표시는 app.js와 style.css다. 사용자 기록은 공개 사이트에서 변경하지 않고 별도 포트에서 검수한다. 기존 45분 판을 새 모드로 바꾸지 않는다. 사진 원본·사람·배경은 공개하지 않는다. 검수 서버는 작업 종료 시 정리한다.
