# 클래식 동행 진행 기록

## 1. 2026-11-08 첫 검토본
실물 클래식 2인 진행 도우미 구현. 30/45/60분 목표, 빠른 시작/기본 준비, 상황 8종, 임대료 계산, 마지막 라운드, 수동 자산 결산, 동점/파산 종료, 기기 로컬 이어하기를 제공한다.

순수 함수 시험 12건 통과. 실제 브라우저에서 빠른 준비 → 진행 → 일시정지 → 임대료 계산(7×10=70) → 새로고침/이어하기 → 마지막 라운드(1회씩) → 결산(1460/1530) → 결과 경로를 확인했다. 기본 준비 30분 모드와 파산 종료도 확인했다. 이름의 HTML 표시는 문자가 그대로 나왔다. 390px 폭을 검사하고 제목 줄바꿈을 조정했다. 등록부 기존 4행은 값 단위 비교로 보존을 확인했다.

실제 가족 플레이의 소요시간·재미·시작 세트 균형은 미검증이다. 60분 실제 대기, 새로고침 이후 진행 중 타이머의 장시간 경과, 저장 공간 오류 경로는 브라우저에서 실측하지 않았다. 시간 함수는 자동 검사로 확인했다. 파일 직접 열기는 일반 스크립트로 지원하도록 작성했으나 Codex 브라우저는 file 프로토콜을 허용하지 않아 해당 경로를 검증하지 못했다.

기존 GitHub Pages용 소스와 허브 등록만 반영했다. 커밋·푸시·외부 배포는 하지 않았다. 휴대폰 공개 URL은 배포 후 생긴다.

## 2. 2026-11-08 아이패드용 매니저
사용자가 인터넷 접속과 아빠·서우, 핵심만 알려주는 매니저를 요청했다. 기본 플레이어를 아빠·서우로 바꾸고, 예전 기본 이름을 쓰던 진행 판의 차례·시간을 보존하며 이름만 바꾼다. 상황 8종 모두 한 행동과 선택으로 갈라 안내한다. 주인 없는 땅 첫 화면은 살래요/안 살래요 두 개뿐이며 선택 후 구매나 경매를 안내한다. 상세 설명은 접힌 항목에 둔다.

17건 자동 검사 통과. 브라우저에서 구매, 이전 안내, 경매, 서우 낙찰, 전기·수도 10배 계산 7→70을 확인했다. 사용자 판의 2차례씩 완료 기록을 유지했다. 검수 중 시간은 일시정지했다. 1366×1024 가로와 1024×1366 세로 화면으로 검사한다. 실제 아이패드 Safari 실기기는 아직 미확인이다. 기존 GitHub Pages main/루트 배포 설정과 원격 main 일치를 확인했다. 배포 완료 여부는 실제 배포 상태와 외부 주소를 확인한 뒤 채팅으로 보고한다.

## 3. 2026-11-08 한국판 사진 대조 · 한 화면 준비 · 보드 동행
사용자 제공 사진 6장에서 한국판 40칸 이름·가격·지폐 배분·사회사업기금·전력회사·수자원공사·저당·세금을 대조했다. 영문·슬로건·장식·추천 문구를 제거하고 준비 세 페이지를 한 화면으로 합쳤다. 1366×1024와 1024×1366에서 가로 넘침 없이 시작 버튼까지 화면 안에 표시된다(각 버튼 하단 727px/718px 미만).

사용자가 실제 보드와 같은 판을 웹에서도 진행하기를 요청하고 실물 주사위 두 숫자 입력을 선택했다. board.js에 말·현금·권리증·주택·호텔·저당 기록을 두고, 구매·경매·임대료·세금·카드 지시·거래·건설·수정·한 번 되돌리기를 제공한다. 웹 주사위 버튼은 없다. 역·공공 기관·세금·출발은 계산하며, 사진 없는 도시 임대료/건축비는 최초 사용 시 실물 권리증에서 확인받는다. 권리증별 해당 주택 수의 임대료를 기억하고 독점 두 배를 계산한다. 실물 카드 지시도 사용자가 입력한다. 진행은 해당 브라우저에 저장되며 다른 기기로 자동 공유되지 않는다.

자동 검사 34건 통과. 브라우저에서 아빠의 용인 M60 구입, 서우의 임대료 M4 지불과 되돌리기, 창원 주택 M100 건설, 용인↔현금 M20 거래와 되돌리기, 같은 차례 수 종료와 자동 결산 M1504/M1496을 확인했다. 검수는 사용자 기록과 분리한 포트 8001에서 수행했다. 건설·판매 균등, 은행 주택32/호텔12 제한, 저당 인수 비용, 감옥·더블·현금 부족의 원자성은 자동 검사로 확인했다. 10% 계산의 부동소수 올림 오류는 정수 비율 계산으로 바로잡았다.

이전 도움말 판에는 위치·현금·권리증 이력이 없으므로 자동 추정하지 않는다. '현재 판 입력'으로 수동 대조하거나 새 판을 시작한다. 실제 아이패드 Safari 기기와 가족 한 판 소요시간은 미검증이다. 사진은 읽기용 로컬 사본으로만 처리했고 저장소·웹에는 올리지 않는다. 배포 성공은 Pages 상태와 최신 외부 페이지에서 확인한 뒤 보고한다.

## 4. 2026-11-08 가로형 디자인 · 실물 그림
준비를 설정/지폐/두 사람 배분의 한 화면으로 정돈했다. 게임 제목·바깥 잔액 막대·도시 색 띠를 제거하고 보드 안쪽 상단에 차례·위치·잔액, 오른쪽 아래에 일시정지·마무리·준비를 고정했다. 소유자 이름과 주택 수/호텔/저당을 별도 표시한다. 실물 주사위는 두 그룹의 여섯 점 모양 면에서 고르며 두 면을 선택한 뒤 이동한다. M은 숫자와 분리된 가는 세리프 화폐 기호로 표시한다. 보유 부지 창에서 두 사람의 잔액을 전환해 확인한다.

사용자의 같은 그림 요청으로 특수 칸 그림만 사진에서 추출한 PNG 13개를 추가했다. 앞 절의 사진 미공개 조건에서 이 그림 조각만 예외이며 원본 전체·사람·배경은 올리지 않는다. 출처와 범위는 assets/README.md에 기록했다.

자동 검사 34건 및 app.js 구문 검사 통과. 분리된 8001 검수 판에서 면 재선택, 한 면만 선택 시 이동 차단, 일시정지 후 선택 보존, 합 5 이동과 광주역 구입, 상대 임대료 M25, 창원 주택 1채, 자산 창 전환을 확인했다. 1366×1024에서 행동/차례 전환 전후 상단 좌표 110.625px와 높이 96px가 같았다. 1024×768에서 페이지 크기는 정확히 1024×768, 주사위 면 55px, 하단 조작 끝 748px다. 준비 시작 버튼 하단은 1194×834에서 728.75px, 1024×768에서 691.75px로 한 화면에 들어온다. 특수 칸 이미지 18곳 모두 정상 디코딩했다. 실제 아이패드 Safari 실기기는 미확인이다.
