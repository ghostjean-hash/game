# 클래식 동행 진행 기록

## 1. 2026-11-08 첫 검토본
실물 클래식 2인 진행 도우미 구현. 30/45/60분 목표, 빠른 시작/기본 준비, 상황 8종, 임대료 계산, 마지막 라운드, 수동 자산 결산, 동점/파산 종료, 기기 로컬 이어하기를 제공한다.

순수 함수 시험 12건 통과. 실제 브라우저에서 빠른 준비 → 진행 → 일시정지 → 임대료 계산(7×10=70) → 새로고침/이어하기 → 마지막 라운드(1회씩) → 결산(1460/1530) → 결과 경로를 확인했다. 기본 준비 30분 모드와 파산 종료도 확인했다. 이름의 HTML 표시는 문자가 그대로 나왔다. 390px 폭을 검사하고 제목 줄바꿈을 조정했다. 등록부 기존 4행은 값 단위 비교로 보존을 확인했다.

실제 가족 플레이의 소요시간·재미·시작 세트 균형은 미검증이다. 60분 실제 대기, 새로고침 이후 진행 중 타이머의 장시간 경과, 저장 공간 오류 경로는 브라우저에서 실측하지 않았다. 시간 함수는 자동 검사로 확인했다. 파일 직접 열기는 일반 스크립트로 지원하도록 작성했으나 Codex 브라우저는 file 프로토콜을 허용하지 않아 해당 경로를 검증하지 못했다.

기존 GitHub Pages용 소스와 허브 등록만 반영했다. 커밋·푸시·외부 배포는 하지 않았다. 휴대폰 공개 URL은 배포 후 생긴다.

## 2. 2026-11-08 아이패드용 매니저
사용자가 인터넷 접속과 아빠·서우, 핵심만 알려주는 매니저를 요청했다. 기본 플레이어를 아빠·서우로 바꾸고, 예전 기본 이름을 쓰던 진행 판의 차례·시간을 보존하며 이름만 바꾼다. 상황 8종 모두 한 행동과 선택으로 갈라 안내한다. 주인 없는 땅 첫 화면은 살래요/안 살래요 두 개뿐이며 선택 후 구매나 경매를 안내한다. 상세 설명은 접힌 항목에 둔다.

17건 자동 검사 통과. 브라우저에서 구매, 이전 안내, 경매, 서우 낙찰, 전기·수도 10배 계산 7→70을 확인했다. 사용자 판의 2차례씩 완료 기록을 유지했다. 검수 중 시간은 일시정지했다. 1366×1024 가로와 1024×1366 세로 화면으로 검사한다. 실제 아이패드 Safari 실기기는 아직 미확인이다. 기존 GitHub Pages main/루트 배포 설정과 원격 main 일치를 확인했다. 배포 완료 여부는 실제 배포 상태와 외부 주소를 확인한 뒤 채팅으로 보고한다.
