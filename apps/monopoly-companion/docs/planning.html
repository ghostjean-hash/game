0.1. 같은 판을 웹에서도 진행 (추가 요청)

실제 보드와 같은 말 위치·현금·권리증·주택·호텔·저당을 웹에서도 유지한다. 준비 화면은 하나로 유지하고, 새 판부터 웹 기록을 시작한다. 실물 주사위 두 숫자를 입력한다. 굴림·구매·경매·임대료·세금·카드 지시 입력·거래·건설·저당을 웹 기록에 반영하고 현재 해결할 행동을 표시한다. 실제로 처리한 뒤 확인한다. 마지막 작업 되돌리기와 실물 기준 기록 수정 기능을 제공한다.

권리증 전체 임대료·건축비 사진은 없으므로 도시 임대료는 필요한 줄을 처음 사용할 때 입력받아 그 부지의 해당 주택 수별로 기억한다. 건물 없는 기본 임대료는 색 세트의 두 배를 웹이 계산한다. 역 25/50/100/200과 공공 기관 4/10배, 사진에서 확인한 세금·지폐·부지 가격은 자동 계산한다. 도시 임대료와 건축비를 임의로 넣지 않는다. 찬스·사회사업기금은 실물 카드 지시를 선택해 현금/이동/감옥/탈출권을 처리한다. 카드가 별도 임대료를 지정하면 그 금액을 입력한다.
