모노폴리 클래식 동행

1. 목표와 범위

부모와 초4 아이가 실물 클래식 보드로 준비부터 결산까지 30~60분 목표로 즐기는 진행 도우미. 설명서를 먼저 외우지 않고 상황을 눌러 읽는다. 실물 주사위·말·돈·권리증을 사용하며 매 이동/거래를 웹에 입력하지 않는다. 규칙은 공식 요약, 단축은 제안한 별도 규칙이다. 승패·집 짓기를 경험할 수 있도록 시작 조건을 바꾸지만 실플레이 재미/균형은 미검증이다.

2. 이번 작업 계획

이 문서를 먼저 작성한 뒤 준비 마법사, 시간/차례 진행, 상황별 규칙과 계산 보조, 자산 결산과 로컬 이어하기를 구현한다. 핵심 함수 시험과 실제 브라우저 경로를 검증한다. 기존 허브 앱 등록부에 한 행 추가한다. 사용자 요청 없이 커밋·푸시하지 않는다. 배포는 기존 GitHub Pages 흐름을 따르며 이번에는 로컬 검토본을 제공한다.

3. 우리 집 단축 규칙 (제안 · 공식 아님)

총 목표 30/45/60분에서 준비 5분·결산 5분을 제외한 플레이 타이머는 20/35/50분이다. 준비·결산 시간은 예상치다. 시간이 끝나면 진행 중인 차례를 끝내고 두 사람 차례 횟수를 맞춰 결산한다. 따라서 목표 시간을 조금 넘을 수 있다. 일시정지는 실제 플레이를 멈출 때만 사용한다.

빠른 시작은 주황 세트(180·180·200)와 빨강 세트(220·220·240)를 사용한다. 첫 사람을 무작위로 정한 뒤 그 사람이 두 세트 중 선택하고 다른 사람이 남은 세트를 받는다. 기본 시작 돈 1500에서 받은 세트의 인쇄 가격 합계를 지불하므로 남는 돈은 주황 940·빨강 820이다. 양쪽 시작 총자산은 1500으로 같지만 색깔별 임대료·건축비·위치는 달라 공정성이 보장되지는 않는다. 금액이 다른 실물판이면 각각 세트 가격 합계를 수정한다. 첫 차례부터 집 짓기가 가능하다. 색 세트 지급 없이 기본 준비를 선택할 수도 있다. 경매·기본 수입·감옥·건설은 기본 규칙을 유지한다. 무료 주차 보너스·개인 간 대출은 넣지 않는다.

마지막 자산은 현금 + 담보 아닌 땅의 인쇄 가격 + 담보 땅의 담보금액 + 건물 구매금액 전액으로 합산한다. 호텔은 집 다섯 채 가격이다. 이 공식은 이 앱의 시간제 결산 약속이며 건물 판매가격(절반)과 다르다. 현금·각 합계는 실물을 보고 입력한다. 빈칸을 0으로 간주해 승자를 확정하지 않으며, 직접 0을 입력해야 한다. 동점은 공동 승리. 두 명 중 한 명이 파산하면 다른 사람이 즉시 승리하며 자산 입력은 필요 없다.

5. 화면과 저장

시작: 시간·이름·빠른 시작 선택. 준비: 돈/땅 배분 → 보드/카드 → 약속 확인. 진행: 남은 시간·현재 사람·차례 완료, 펼치는 상황 도움말, 교환 제안, 임대료 계산. 더블의 추가 굴림은 같은 차례이며 버튼은 모든 굴림이 끝난 뒤 누른다. 종료 경고는 차례 횟수가 같아질 때까지 안내한다. 시간 종료 이후 새 라운드는 열리지 않는다. 일찍 마무리도 같은 방식이다. 결산 진입 전 안내 화면에서 차례로 돌아갈 수 있다. 결산 중 뒤로 가기도 가능하다.

저장 키 gg.monopoly-companion.session 하나에 준비 단계·이름·선택·차례 횟수·누적 경과시간·실행 기준시각·결산 입력을 보관한다. 새로고침·백그라운드에서도 기준시각 차이로 경과시간을 계산한다. 일시정지 시간은 제외한다. 화면에 이어하기와 새 판 확인을 제공한다. 지원하지 않는 형식/손상값은 새 판으로 돌아간다. 저장 실패 시 화면에 알린다. 기기 간 동기화는 하지 않는다.

6. 검증 기준

시작 돈 합계, 시간이 지난 후 차례가 같아지는 종료, 더블의 추가 굴림 안내, 일시정지/재개/새로고침, 음수·비정수·빈 결산 입력 차단, 동점, 파산, 이름의 HTML 처리, 모바일 가로 넘침과 모든 진입/뒤로 가기를 확인한다. 테스트 통과와 실제 30~60분 가족 플레이 검증은 구분한다.

7. 2026-11-08 사용자 확인 후 수정

플레이어 기본값은 아빠·서우다. 예전 나·딸 기본 이름이 남은 판만 아빠·서우로 옮기고 직접 쓴 이름과 진행 기록은 보존한다. 새 판에서는 두 이름이 바로 선택돼 있다. 12.7인치 아이패드를 식탁 위에 두고 읽는 화면을 기준으로 한다. 화면 크기는 인치가 아니라 가로 1024~1366px 및 세로 768~1024px 구간과 세로 방향을 확인한다.

도움말은 긴 설명서가 아닌 매니저 방식으로 바꾼다. 한 화면에 현재 상황, 해야 할 행동 한두 문장, 다음 선택 버튼만 둔다. 주인 없는 땅은 살까요 → 산다: 은행에 인쇄 가격 지불·권리증 받기 / 안 산다: 경매 → 낙찰자 선택 → 낙찰금 지불·권리증 받기로 안내한다. 아무도 입찰하지 않으면 은행에 남긴다. 임대료는 땅 종류·건물·담보별로 갈라 해당 경우만 보여준다. 더블·감옥·건설·특수 칸·거래·부채도 상황별 선택 뒤 필요한 행동만 보여준다. 되돌아가기는 웹 안내만 되돌리며 실제 돈·말 이동은 자동 복구하지 않는다고 표시한다. 세부 규칙과 출처는 접힌 항목 안에 보관한다. 타이머는 설명을 보는 동안 계속 흐르며 대화상자에서 직접 멈춤/재개할 수 있다.

진행 화면에서도 매니저가 현재 사람에게 굴리기 → 도착 칸 처리 → 추가 굴림까지 끝나면 차례 완료를 짧게 안내한다. 큰 버튼과 큰 글자를 사용한다. 기존 정적 GitHub Pages 인터넷 배포를 우선 사용하고 실제 외부 주소 응답과 최신 내용 반영을 확인한 뒤 접속 가능하다고 보고한다. 배포를 위한 해당 앱·등록부 변경만 커밋·푸시하고 다른 미커밋 파일은 포함하지 않는다. 배포 경로 접근이 막히면 사유와 완료된 로컬 범위를 구분한다.
