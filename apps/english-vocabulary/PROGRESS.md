## 2026-08-06 · 아카이브 신설 (세트에서 통째 제외) + 세트 홈 화면 폐기

- **배경**: 사용자 지시 - "다시 안 볼 단어를 아카이브로 옮겨서 리스트나 목록에서 빼줘. 홈화면에 아카이브 메뉴 신설. 즉 안볼단어 항목이나 수량 자체가 없어져야 해. 아예 원본이 200개가 아닌 3개가 되도록" + "홈에서 리스트를 누르면 서브화면이 한번 더 뜨는데 서브화면 삭제. 서브화면 정보에는 관심이 없어".
- **규칙 변경(핵심)**: 다시 안 볼 단어를 "분모에서 뺀 것"이 아니라 **"그 세트에 없는 것"**으로 바꿨다. `stats().total` = 파일 개수 - 아카이브. 200단어 중 197개를 아카이브하면 그 세트는 3단어짜리 세트가 되고, 세트 카드·층 합계·학습 진행·완료 화면 어디에도 아카이브 수가 나오지 않는다. 파일 개수는 `sourceTotal`로만 남기고 화면에 쓰지 않는다.
- **직전 규칙과의 차이**: MASTERED(완전히 외운 단어)를 진도 분자에 남겨 완료율이 뒤로 가지 않게 했던 처리를 폐기했다. 이제 두 갈래 모두 세트에서 빠지므로 외운 단어를 아카이브하면 분자·분모가 함께 줄고 완료율이 달라진다. "아카이브 = 이 세트에서 뺀다"는 사용자 정의를 따른 결과이고 의도된 동작이다.
- **deck.js**: API를 아카이브 어휘로 개명(`bury`→`archiveKnown`, `buryLearned`→`archiveLearned`, `buryAllLearned`→`archiveAllLearned`, `buriedWords`→`archivedWords`, `unbury`→`unarchive`, `BURY_TIER`→`ARCHIVE_TIER`). **저장 문자열은 `status:"buried"`·`buriedTier` 그대로 두어 마이그레이션이 없다.** `stats()`는 `total`(=아카이브 뺀 크기) / `sourceTotal` / `archived` / `archivedKnown` / `archivedMastered`를 주고 옛 `start`·`done`·`buried`·`mastered`는 없앴다.
- **화면 구조**: 세트 홈(`renderHome`) 삭제 - 홈(세트 목록)에서 세트를 누르면 곧바로 학습이다. 없어진 진입점은 이렇게 옮겼다. (a) 복습 → 학습 화면 상단바 버튼 `#nav-vault`(index.html에 신설, 외운 단어가 있고 모음이 아닐 때만 노출). (b) 아카이브 → 홈의 아카이브 카드(점선 테두리, 전 세트 통합). (c) 처음부터 다시·세트 목록으로 → 완료 화면. 설정은 `settingsFrom`으로 들어오기 직전 화면에 돌아간다.
- **아카이브 화면**: 세트를 고르기 전 화면이라 덱이 없을 수 있어, 열 때 아카이브가 있는 세트의 파일만 읽어 목록을 만들고(`openArchive`), 되살리기는 그 세트의 저장본을 직접 고친다(`unarchiveInSource`, 열려 있는 세트면 `buildDeck()`도 다시). 단어마다 출신 세트를 함께 보여 준다. KNOWN 되살리기 접힘 기본은 유지.

## 2026-08-06 · "다시 안 보기" 두 갈래 분리 + 외운 단어 정리 경로

- **배경**: 사용자 지시 - "이미 외운 단어도 다시 안 보기에 넣을 수 있게. 다만 1차는 진짜 기초 단어 또는 이미 알고 있는 단어, 2차는 외운 단어로 정리. 1차는 다시는 안 빼는 경우". 앞선 buried 단일 상태로는 (a) learned에서 buried로 가는 경로가 없어 외운 단어가 복습 목록에 무한정 쌓이고, (b) "애초에 배울 필요 없는 단어"와 "외워서 졸업한 단어"가 한 통에 섞였다.
- **단계 정의**: `BURY_TIER.KNOWN`(1차) = 이미 아는 기초 단어, 학습 대상 자체에서 제외. `BURY_TIER.MASTERED`(2차) = 외운 뒤 복습까지 졸업, 복습 목록에서만 제외.
- **진도 계산이 핵심 결정**: 분모 `start` = 원본 - 1차, 분자 `done` = learned + 2차. 2차는 이미 외운 단어라 분자에 남겨야 완료율이 뒤로 가지 않는다(외운 단어를 정리했다고 진도가 깎이면 정리를 못 쓴다). 1차만 분모를 줄인다. `stats()`에 `mastered`·`done` 추가, `learned`는 "복습 목록에 남은 수"로 뜻을 좁혔다.
- **학습 로직(deck.js)**: `STATE_VERSION` 1→2, progress에 `buriedTier` 필드 신설. `buryLearned(id, now)`(learned → 2차), `buryAllLearned(now)`(일괄), `buriedWords(tier)`(단계별 필터) 추가. `unbury(id)`는 단계에 따라 복귀처가 갈린다 - 1차는 active, 2차는 learned(복습 목록). `normalizeTier()`가 단계 개념이 없던 v1 저장본의 buried를 1차로 읽어 기존 사용자 진도를 그대로 보존한다.
- **화면(main.js)**: 학습 화면 버튼을 "이미 아는 단어 · 1차로 제외"로 명확화(키보드 단축키 부여 안 함은 유지). 외운 단어 목록에 항목별 "2차로 정리" + "외운 단어 전부 2차로 정리"(확인 모달). "묻은 단어" 화면을 "다시 안 볼 단어"로 바꿔 1차·2차 두 묶음으로 나눠 표시. 홈·완료·메뉴 카드 집계를 `done` 기준으로 정렬하고 stat에 "2차 정리 (외움에 포함)" 칸 추가.
- **1차 되살리기 취급**: 사용자 지시대로 되살리기를 기본 노출하지 않는다(원칙은 학습에 다시 넣지 않는 것). 다만 오탭한 단어가 갇히지 않도록 "잘못 넣은 단어가 있나요?" 글줄을 눌렀을 때만 항목별 되살리기가 펼쳐진다. 2차는 상시 "복습으로 되돌리기" 노출.
- **검증**: `tests/run-node.mjs` 332 PASS / 0 FAIL(신규 3묶음 - 2차 정리·단계별 목록·복귀처 분리·저장 왕복, v1 저장본 호환, 일괄 정리). browser-shot 실경로 - 3개 외움 + 1개 1차 제외 후 홈 "199개 중 3개 외움 · 완료율 1.5% · 1차 제외 1개", 1개 2차 정리 후 **완료율 1.5%·외운 단어 3 그대로**(분자 유지 확인)·복습 (3)→(2), 다시 안 볼 단어 화면 1차/2차 분리 표시, 1차 되살리기 펼침, 2차 되살리기 후 복습 복귀, 새로고침 후 상태 유지. 콘솔 에러 0건.
