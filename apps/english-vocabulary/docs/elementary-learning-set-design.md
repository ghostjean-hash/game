# 초등 800 학습 세트 설계·변환 계획

## 목적과 현재 상태

AUTHORING BATCH 01~04는 알파벳 순으로 제작·검수한 작업 단위다. 이를 그대로 앱 SET01~04로 쓰지 않는다. 초등 `*` 대표형 800개는 제작·사전 대조·재감사를 마쳤고, 이제 실제 학습 세트 순서를 **근거를 남기는 별도 설계 작업**으로 정한다.

이 문서는 앱 반영 승인이 아니며, `src/`, `manifest.json`, 기존 playland 데이터·진도를 변경하지 않는다.

## 변하지 않는 입력

- 카드 원본: `authoring-batch-01.json`~`04.json`의 800개
- 표제어 포함 여부: 교육부 2022 개정 별책 14의 초등 `*` 대표형
- 안정 ID: `ev-moe2022-e-0001`~`0800` 유지
- 학습 세트 수: 4개 × 200카드

## 세트 순서의 근거와 금지

교육부 목록은 초등 사용 권장 여부만 제공하고 800개 내부의 학습 순위를 제공하지 않는다. 따라서 다음 둘을 구분한다.

1. **사실**: 어떤 단어를 포함할지는 교육부 목록이 결정한다.
2. **설계 판단**: 어떤 세트에 먼저 둘지는 시중 레벨별 단어장의 일반적인 **주제·상황·의사소통 기능** 단위와 카드 난이도 점검으로 결정한다.

알파벳 순, 기존 playland 세트 순서, 작업자의 감으로 200개씩 나누는 것은 금지한다.

## 채택한 학습 세트 방식

시중 영어 단어장은 대체로 핵심 어휘 목록으로 포함 대상을 고른 뒤, 학습자가 실제로 만나는 주제와 상황을 단위로 구성한다. 문법·기능어·어형은 그 주제 안에서 함께 익히게 하고, 뒤 세트의 복습에서 다시 노출한다.

따라서 이 앱도 다음을 채택한다.

1. **포함 기준**: 교육부 2022 개정 별책 14의 초등 `*` 대표형 800개를 유지한다.
2. **표면 학습 순서**: 단순 알파벳순·전역 빈도순·품사 균등 분배가 아니라, 초등 생활의 주제·상황 묶음으로 4개 세트를 설계한다.
3. **세트 내부**: 각 주제 안에서 자주 쓰는 단어와 쉬운 의미를 먼저 두되, 가족·학교·음식·장소처럼 함께 쓰이는 단어를 가까이 둔다.
4. **기능어와 문법**: 전치사·대명사·조동사 등을 품사 비율에 맞추기 위해 인위적으로 분산하지 않는다. 해당 주제의 문장과 기능에 필요할 때 배치하고, 복습에서 반복 노출한다.
5. **빈도 자료의 역할**: `wordfreq` 순위는 주제 안 우선순위와 복습 우선순위를 판단하는 보조 메타데이터로만 보존한다. 세트 경계를 결정하지 않는다.

`elementary-learning-set-proposal-v1.json`의 품사 균등 제안은 구조 검증용 산출물로 보존하지만, 위 방식을 따르는 최종 세트안으로 승인하거나 앱에 반영하지 않는다.

## 설계 절차

1. 800개 표제어에 생활 주제·상황·의사소통 기능 태그를 붙이고, 주제별 카드 수와 난이도를 점검한다.
2. 각 카드에 빈도 순위와 카드 난이도 신호(품사, 예문 길이, 추상성·다의성 사람 검토)를 보조 설계 데이터로 기록한다. 원본 카드의 단어·뜻·예문은 이 단계에서 바꾸지 않는다.
3. 4개 세트가 생활 주제의 흐름을 이루도록 200개씩 `setId`와 `learningOrder`를 정한다. 한 카드의 `setId`는 하나여야 하고, 800개 누락·중복은 0이어야 한다.
4. 주제의 응집성, 문장에 필요한 기능어, 다음 세트에서의 복습 연결을 사람 검수한다. 품사 비율만 맞추기 위한 이동은 하지 않는다.
5. 설계표(카드 ID, 주제·상황 태그, 세트, 학습순서, 빈도 순위, 조정 사유)를 사람 검수한다.
6. 사용자 승인 뒤에만 리치 카드→앱 스키마 변환·새 manifest·새 저장 키·기존 진도 분리 계획을 구현한다.

## 선정한 빈도 근거

학습 순서의 보조 정량 근거로 `wordfreq` 영어 빈도 데이터를 사용한다. 이 데이터는 여러 자료를 결합한 영어 단어 빈도 추정치를 제공하며, 패키지는 Apache-2.0, 포함 데이터는 CC BY-SA 4.0으로 재배포할 수 있다. 따라서 순위만 설계 메타데이터에 보존하고, 앱 배포 시 데이터 출처·버전·CC BY-SA 4.0 고지를 함께 둔다.

- 원천: `rspeer/wordfreq` (영어 빈도 데이터)
- 사용할 값: 각 공식 표제어의 영어 빈도 추정치와 그에 따른 순위
- 고정할 재현 정보: 도구 버전, 추출일, 정규화 규칙, 원천 URL, 라이선스 고지
- 한계: 일반 영어 사용 빈도이지 한국 초등 교과서의 출현 빈도는 아니다. 따라서 빈도 순위는 주제 안의 우선순위와 복습 우선순위를 사람이 검토할 때만 사용한다.

## 기존 기준선·제안의 위치

단순 빈도 200개 단위 기준선은 SET01에 전치사·대명사·한정사·접속사·조동사가 과도하게 모이고, SET04에는 명사가 147개로 쏠렸다. 이 기준선은 빈도 근거 확인용으로만 보존하고 최종 학습 세트로 사용하지 않는다.

이전 품사 균등 제안은 다음의 재현 가능한 규칙으로 만들었으며, 데이터 완전성·배정 로직 검증에는 활용할 수 있다.

1. 카드의 대표 품사를 기준으로 11개 품사 바구니를 만든다.
2. 각 바구니 안에서는 `frequencyRank` 오름차순을 유지한다.
3. 각 품사 바구니를 전체 비율에 맞춰 SET01~04에 나눈다. 4세트의 목표는 각 세트 200개이며, 명사 약 108개·동사 약 38개·형용사 약 23개를 중심으로 한다.
4. 기능어(전치사·접속사·한정사·대명사·조동사)는 네 세트에 분산하되, 원래 빈도 순위를 보존한다.
5. 동률·나머지 카드의 배정은 낮은 세트 번호 우선으로 고정해 재현성을 보장한다.
6. 결과에는 카드별 `frequencyRank`, `setId`, `learningOrder`, 품사, 배정 사유를 남긴다.

그러나 이 규칙은 시중 단어장의 주제·상황 기반 학습 구조와 다르므로, 최종 학습 세트의 배정 규칙으로 사용하지 않는다. 카드 내용 변경이나 앱 반영은 여전히 하지 않는다.

## 완료 게이트

- 주제·상황·의사소통 기능 태그와 각 세트의 교육적 흐름 기록
- 빈도 자료의 원천·라이선스·추출일 기록
- 800개 모두에 세트와 학습 순서가 하나씩 부여됨
- 세트마다 정확히 200개, 세트 간 중복·누락 0
- 주제 응집성·기능어 맥락·복습 연결·추상어 편중 검토 결과와 조정 사유 보존
- 변환 전 설계표에 대한 사용자 승인

2. 4개의 주제 기반 학습 세트와 세트별 복습 연결을 설계한다.
