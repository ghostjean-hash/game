# 영어 단어장 - 전체 단어 제작 마스터 플랜 (초중고 3,000)

이 문서는 `english-vocabulary`의 단어 제작·검증·앱 반영 순서를 정하는 단일 진실(SSOT)이다. 단어를 임의로 선정하거나, 자동 생성 결과만으로 완료 처리하지 않는다.

작성 근거: 사용자 지시(2026-07-24, 2026-07-29) - 초중고 3,000단어를 사실 근거로 제작하고, 단어 작성과 검증을 최우선으로 할 것.

## 1. 목표와 현재 범위

1. 최종 목표는 교육부 2022 개정 영어과 교육과정 별책 14의 **대표형 3,000개**를 학습 카드로 제작하는 것이다.
2. 초등 사용 권장 `*` 대표형 **800개**의 AUTHORING BATCH 01~04는 제작·사전 대조·재감사를 완료했다. 다음 범위는 800개를 실제 학습 SET01~04로 배치하는 설계 단계다.
3. 제작 배치(AUTHORING BATCH)는 검수 작업 단위이고, 학습 세트(LEARNING SET)는 실제 앱의 학습 순서다. 둘을 같은 것으로 취급하지 않는다.
4. 현재 제작 산출물은 앱 밖 `docs/sources/`에만 둔다. 기존 playland 데이터·앱 코드·manifest·사용자 진도는 이 계획 단계에서 변경하지 않는다.

## 2. 공식 원천과 허용되는 근거

| 항목 | 확정 근거 | 위치 | 용도 |
|---|---|---|---|
| 표제어·학교급 표기 | 교육부 고시 제2022-33호, 별책 14 | `docs/sources/moe-2022-english/` | 카드 포함 여부의 유일한 근거 |
| 초등 표제어 800개 | 위 원천의 `*` 대표형 | `elementary-800-cards.json` | BATCH 01~04 입력 |
| 전체 표제어 3,000개 | 위 원천의 대표형 | `vocab-3000-repforms.txt`, `vocab-leveled.csv` | 이후 중·고 공통·심화 범위 입력 |
| 품사·뜻 사실 확인 | 실제 조회한 공개 사전 2종 | `lexical-crosscheck-batch-NN.md` | 품사 대조와 뜻 선택 근거 |
| 예문·한국어 번역 | 자체 작성 + 사람 검수 | 각 배치 JSON·검수 기록 | 앱용 학습 문장 |

원천 밖의 단어는 넣지 않는다. 상용 사전 문장을 복사하지 않는다. 공개 사전은 사실 확인용이며, 최종 뜻과 예문은 짧은 학습용 표현으로 새로 작성한다.

## 3. 변하지 않는 작성·검증 규칙

상세 규칙은 `docs/vocab-authoring-rules.md`가 권위다. 이 계획에서는 다음 게이트를 절대 생략하지 않는다.

1. 공식 원천의 순번·표제어와 카드가 정확히 일치해야 한다.
2. 카드마다 대표 품사, 핵심 뜻 1~2개, 짧은 예문과 자연스러운 번역을 작성한다.
3. `tools/validate-batch.mjs`에서 오류 0이어야 한다.
4. `tools/lexical-crosscheck.mjs <배치번호> --fetch --report`로 **실제** 공개 사전을 조회한다. 품사 불일치는 0이어야 하며, 다의어·추상어·뜻 2개 카드는 사람이 정의를 읽고 뜻 선택 이유를 남긴다.
5. 1차 검수(사실·형식)와 2차 검수(품질·일관성)를 서로 독립적으로 수행하고 수정 이력을 기록한다.
6. 각 배치 완료 뒤 결과를 보고하고, 다음 배치는 사용자 승인 뒤에만 시작한다.

## 4. 초등 800 완성 실행 계획

| 배치 | 공식 순번 / 범위 | 상태 | 착수 전·후 산출물 |
|---|---|---|---|
| BATCH 01 | 001~200, `a`~`date` | 완료 | JSON·사전 대조·2회 검수 기록 보존 |
| BATCH 02 | 201~400, `daughter`~`kind` | 완료 | JSON·사전 대조·재감사 기록 보존 |
| BATCH 03 | 401~600, `king`~`service` | 완료 | JSON·사전 대조·재감사 기록 보존 |
| BATCH 04 | 601~800, `set`~`zoo` | 완료 | JSON·사전 대조·재감사 기록 보존 |

각 배치는 아래 순서만 따른다.

1. 조립 도구가 없다면 먼저 `tools/assemble-batch.mjs`를 만든다. 사람이 판단한 압축 초안 외의 필드(id·표제어·sourceOrder·marker·null 세트 정보)는 공식 원천에서 자동 조립한다.
2. 40개씩 다섯 소묶음으로 순차 작성한다. 200개를 한 번에 자동 생성해 끝내지 않는다.
3. 조립 시 순번↔표제어 불일치, 누락, 중복은 즉시 실패 처리한다.
4. 자동 형식 검증과 사전 실조회 대조를 실행한다.
5. 1차 검수에서 사실·문법·뜻 일치를 고치고, 2차 검수에서 뜻 중복·문장 패턴·난이도·번역투·편중을 전체 재검토한다.
6. 배치 JSON, 사전 대조 보고서, 검수 기록을 함께 보존한다. 앱에는 적용하지 않는다.

## 5. 초등 제작 완료 뒤의 별도 결정

800개 제작 완료는 앱 적용 승인이 아니다. **사용자 경고(2026-07-29): 초등 800개가 모두 끝나도 다음 단계로 넘어가지 않는다.** 전수 검증 결과만 보고하고, 이후 진행에 관한 질문·권장·추천을 하지 않는다. 사용자가 먼저 명시적으로 지시할 때만 아래 설계·변환·앱 반영 작업을 시작한다.

1. 800개를 빈도·활용도·난이도로 네 개의 LEARNING SET에 배치한다. 알파벳 제작 순서는 학습 순서로 쓰지 않는다.
2. 제작용 리치 스키마를 앱 스키마로 매핑하고, 기존 playland 진도와 분리된 새 데이터 버전·저장 키를 설계한다.
3. 변환 결과에 `validate-data.mjs`를 적용하고, 세트 간 중복·누락·각 200개를 검증한다.
4. 앱 반영 전 데이터 마이그레이션·진도 처리·화면 검증 계획을 사용자에게 제시해 승인받는다.

## 6. 중·고 2,200개 계획

공식 원천에는 `**` 공통 1,200개와 무표시 심화 1,000개도 이미 있다. 다만 별표가 중학교 전용/고등학교 전용을 직접 구분하지 않으므로, 초등 800 완료 전에는 임의로 6세트·5세트에 배분하지 않는다.

중등 출제 범위는 사용자 승인(2026-07-29)으로 공식 `**` 대표형 1,200개 전체로 확정한다. 이는 중·고 공통 권장이라는 원천 표기와 충돌하지 않으며, 이 앱의 중등 콘텐츠 6세트(각 200개) 입력으로 사용한다. 고등 범위는 무표시 대표형 1,000개 전체로 유지한다.

중등은 다음 순서로 진행한다.

1. 공식 대표형 원천에서 `**` 1,200개를 분리·고정하고, 200개 단위 AUTHORING BATCH 01~06을 만든다.
2. 초등과 동일한 작성·실조회·2회 검수·사용자 승인 게이트를 적용한다.
3. 전 3,000개 완료 뒤에만 15세트 구성과 앱 반영을 검토한다.

## 7. 제작 완료 현황 (2026-07-30)

초등 800 / 중등 1,200 / 고등 1,000, 합계 3,000개 제작·검수 완료. 층별 배치와 검수 기록은 `docs/sources/moe-2022-english/`에 보존한다.

| 층 | 원천 표기 | 카드 | 배치 파일 | 검수 기록 |
|---|---|---|---|---|
| 초등 | `*` | 800 | `authoring-batch-01~04.json` | 배치별 `-review.md`·`-audit.md` |
| 중등 | `**` | 1,200 | `middle-authoring-batch-01~06.json` | 배치별 `-review.md` + `middle-1200-final-audit.md` |
| 고등 | 무표시 | 1,000 | `high-authoring-batch-01~05.json` | 배치별 `-review.md` |

3,000 통합 전수 검사 결과는 `vocab-3000-final-audit.md`. 단어·예문·번역 중복 0, 같은 층 안 뜻 중복 0, 공식 순번 불일치 0.

다음 단계(15세트 구성·앱 반영)는 사용자가 명시로 지시할 때만 착수한다. 모든 카드의 `setId`·`learningOrder`는 null 상태다.

## 7. 완료 정의와 금지 사항

### 배치 완료

- 공식 표제어 200개와 정확히 일치
- 카드 200개 누락·중복 0
- 자동 검증 오류 0, 사전 대조 품사 불일치 0
- 1차·2차 검수 기록 및 수정 근거 보존
- 앱 파일 변경 0
- 사용자에게 결과 보고 완료

### 금지

- 감으로 단어를 더하거나 빼기
- 기존 playland 카드의 뜻·품사·예문을 초안으로 재사용하기
- 사전 조회 없이 기억에 의존해 사실 확인을 했다고 주장하기
- 자동검사만 통과시키고 사람 검수를 생략하기
- 배치 완료를 이유로 다음 배치나 앱 반영을 자동 진행하기
