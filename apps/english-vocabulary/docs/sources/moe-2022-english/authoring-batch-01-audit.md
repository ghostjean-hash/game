# AUTHORING BATCH 01 재감사 기록

감사일: 2026-07-29. 대상: 공식 순번 001~200(`a`~`date`) 카드 전수.

## 감사 기준

각 카드에서 공식 표제어, 대표 품사 1개, 대표 뜻 1개(필요 시 2개), 예문에서 실제 쓰인 뜻, 한국어 번역의 일치 여부를 다시 확인했다. 자동 검증 통과 여부와 별개로, 한 카드에 여러 품사·서로 다른 뜻을 섞어 회상 학습을 흐리는 경우를 결함으로 처리했다.
